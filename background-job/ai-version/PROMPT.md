# AI Rematch Prompt

Build the same system using Python 3.10+, FastAPI and Inngest. Implement `GET /health` with HTTP 200. Implement `POST /reports` with a required non-empty `topic`; invalid input must return 400 without sending an event. Valid input creates an ID, stores `pending`, sends `report/requested`, and returns 202 immediately. Implement `GET /reports/{id}` with 404 for unknown IDs. The `make-report` Inngest function must be triggered by `report/requested`, sleep 8 seconds in one durable step, then build and save the result in a separate durable step. Topic `fail` must raise an error. Configure 2 retries. Add `say-hello` on `test/hello` with a 5-second sleep. Add `heartbeat` on cron `* * * * *` and log pending/done/failed counts. Serve all functions at `/api/inngest`. Document commands, endpoint/function table, retry proof, cron expressions and idempotency.
